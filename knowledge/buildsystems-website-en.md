# BuildSystems Website

Description: Developed the BuildSystems website using the Astro framework, leveraging the Notion API as a CMS.
Tags: Web Development, Astro, Notion API, TypeScript

Date: August 2023 – April 2024
Link: https://buildsystems.de

Developed the BuildSystems website using the [Astro](https://astro.build/) framework, leveraging the Notion API as a content management system. The website showcases BuildSystems' products and services for sustainable construction planning.

The tech stack includes Astro with TypeScript, Tailwind CSS for styling, and the Notion API for content management, enabling the team to update website content directly from their existing Notion workspace.
