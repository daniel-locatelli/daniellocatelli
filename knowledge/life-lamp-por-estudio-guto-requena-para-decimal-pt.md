# Life Lamp por Estúdio Guto Requena para Decimal

Description: O processo de design é um híbrido entre uma abordagem de cima para baixo e de baixo para cima. Trabalhamos tanto com modelos 3D predefinidos em forma de coração como base de design quanto com modelagem baseada em agentes, amplamente explorada por Craig Reynolds na década de 1980. A parte de programação foi desenvolvida usando Grasshopper 3D, o plugin Culebra v2.0 de duas semanas para a modelagem baseada em agente em conjunto com o plugin Firefly para capturar os batimentos cardíacos. Este trabalho tornou-se posteriormente um paper apresentado na ECAAD 2020.

## Conceito
> Um objeto sensível composto por diferentes camadas e cuja sombra única resulta numa imagem complexa que expressa os caminhos e surpresas da nossa existência.

A [Decimal](https://decimalmade.com/) fabrica e vende luminárias de designers renomados no mundo todo, e eles convidaram Guto Requena para propor um conceito para um de seus produtos. A Life Lamp representou um esforço duplo, um projeto e uma iniciativa de pesquisa. Como freelancer, dediquei minhas tardes para trabalhar com o [Estúdio Guto Requena](https://en.gutorequena.com/), contribuindo para a estratégia computacional e dando vida ao conceito já estabelecido.
O processo de design é um híbrido entre uma abordagem de design top-down e bottom-up. Trabalhamos tanto com modelos 3D predefinidos em forma de coração como base de design quanto com modelagem baseada em agentes, amplamente explorada por Craig Reynolds na década de 1980.
## Desenvolvimento
A parte de programação foi desenvolvida usando Grasshopper, o plugin Culebra v2.0 para modelagem baseada em agentes em conjunto com o plugin Firefly para capturar os batimentos cardíacos.
Este trabalho se tornou mais tarde um artigo apresentado no ECAAD 2020.
