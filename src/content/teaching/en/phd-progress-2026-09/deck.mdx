<Slide>
  <div class="pp-head">
    <h3>The big picture · 3 of 4</h3>
    <h2>Skills as deliverables, for <em>property-based development</em></h2>
  </div>
  <div class="pp-skill">
    <div class="sk-doc">
      <div class="sk-tab"><b>SKILL.md</b><span>urform / strategies / agent-based-modeling</span></div>
      <div class="sk-page">
        <div class="sk-front"><i>---</i><br /><b>name:</b> agent-based-modeling<br /><b>description:</b> Use when a design task needs agents relaxing on a surface to produce a tessellation or plate layout, in any host (Grasshopper, web, Revit, Blender).<br /><i>---</i></div>
        <p class="sk-h1"><i>#</i> Agent-based modeling for surface tessellation</p>
        <p class="sk-h2"><i>##</i> Overview</p>
        <p>Agents are points constrained to a surface; simple summed behaviours relax them into a near-hexagonal packing. <strong>Implement the strategy natively in each host, do not transliterate the reference.</strong></p>
        <p class="sk-h2"><i>##</i> Workflow</p>
        <ol>
          <li><strong>Host adapter:</strong> implement <code>ISurfaceHost</code>, nothing else touches host types</li>
          <li><strong>Tune in the console harness first</strong>, seconds per run</li>
          <li><strong>Check the report before looking at pictures</strong></li>
        </ol>
        <p class="sk-h2"><i>##</i> Acceptance, in four classes</p>
        <table>
          <tr><th>class</th><th>example</th></tr>
          <tr><td><strong>Invariant</strong>, assert exactly</td><td>closed surface: plates = agents</td></tr>
          <tr><td><strong>Banded</strong>, assert with a band</td><td>side ratio median 0.38 to 0.46</td></tr>
          <tr><td><strong>Identity</strong>, never evidence</td><td>Euler's formula</td></tr>
          <tr><td><strong>Not portable</strong></td><td>seed-for-seed agent positions</td></tr>
        </table>
        <p class="sk-h2"><i>##</i> Common mistakes</p>
        <p>Each one cost a debugging round.</p>
        <ul>
          <li><strong>Plates from Voronoi</strong> instead of the tangent-plane intersection</li>
          <li><strong>Spacing from the plan area</strong>, which under-estimates on curved patches</li>
          <li><strong>A lattice edge along an asymptotic direction</strong>: zero-length plate sides</li>
        </ul>
      </div>
    </div>
  </div>
  <SlideNotes>Instead of a Grasshopper plugin, ship composable agent skills with a property-first specification. A skill is the container of knowledge: what to build, how, and how to check it. Properties are the contract every implementation has to pass, in any language; implemented in Grasshopper first, validated, then made language-agnostic. The example is an excerpt of the agent-based modeling skill in urform: four hosts (Grasshopper script, Grasshopper plugin, .NET console, compas_timber in Python sharing no code with the C# core), which is how seven defects in the normative document were found. Code is cheap, so we do not have to commit to one language: the same skill can be built in Grasshopper, Revit, Cadwork or SEMA. Open conditions: defensible (evidence a skill works), demonstrable (one chain a reader can run), durable (plugins rot with Rhino versions, skills rot against models).</SlideNotes>
</Slide>

    <h2>Cheap, quick checks inside an <em>agentic form-finding loop</em></h2>
  </div>
  <div class="pp-loop">
    <div class="pl-agent">Agent proposes a form</div>
    <div class="pl-tool"><em>generate</em><b>Paneling algorithm</b><span>agents relax on the surface into a plate layout</span></div>
    <div class="pl-checks">
      <em>check</em>
      <div><b>Structural analysis</b><span>equilibrium first, FEA last</span></div>
      <div><b>Acoustics</b><span>reflection, diffusion, absorption</span></div>
      <div><b>Fabrication</b><span>plate size, bevel, stock, BTLx</span></div>
    </div>
    <div class="pl-back">↺ verdicts back to the agent, in seconds</div>
  </div>
  <SlideNotes>The agent does not draw plates itself: it calls the paneling algorithm (the agent-based modeling skill) to turn a surface into a plate layout, then runs the checks on that layout. The loop only works if every check is cheap enough to run on every candidate. Expensive checks verify the few candidates that survive. The rest of the talk goes through each check: plates, structure, acoustics, assembly.</SlideNotes>
</Slide>
