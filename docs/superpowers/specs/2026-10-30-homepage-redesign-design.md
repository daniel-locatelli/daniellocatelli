# Homepage redesign: essays, a floating chat, and Work · CV

Date: 2026-10-30
Status: approved in brainstorming, ready for an implementation plan

## Why

The homepage sells what LLMs made cheap: plugin development, web apps,
dashboards, a skills map. Daniel's recent thinking (thought store, `PhD/` and
`Research/`, June to October 2026) runs the other way: code is cheap now, and
the scarce work is method, definitions, and deciding what counts as correct.
The site should lead with that argument, and it should get simpler, not grow.

Reference for tone and density: darioamodei.com (a name, a short bio, a few
long essays, almost no navigation).

## Decisions

| Question | Decision |
|---|---|
| Primary audience | Thought leadership: AEC practitioners and offices asking what LLMs mean for them |
| Core claim | Code is cheap, judgement isn't |
| Where the argument lives | A few long essays, one per month, listed on the homepage; no notes stream, no essays index page |
| Scope | Homepage and header nav; no content is deleted or retired |
| AI chat | Stays as the hero, restyled to float (no container) |
| Visual direction | B: current identity (zinc, green, Montserrat headings, Poppins body), stripped down |
| Nav | Work · CV, plus the language picker |
| URLs | No URL changes and no redirects |

## 1. Homepage

File: `src/pages/[...locale]/index.astro`. Visual reference:
`.superpowers/brainstorm/5836-1793371326/content/homepage-final.html`
(checked at 1440 px and 390 px, no horizontal overflow).

Layout: one centred column, 688 px max width with 24 px side padding.
Top to bottom:

1. **Header** (shared `Header.astro`): DL logo left; Work, CV, divider,
   language picker right.
2. **Intro**: `h1` "Daniel Locatelli" (Montserrat 600, 44 px; 36 px on
   phones). Role line in muted text: "Doctoral researcher, Gramazio Kohler
   Research, ETH Zurich". Bio (Poppins, 17 px):
   "I research how timber plate structures are designed and built, and how AI
   changes the way architects and engineers work."
3. **Chat (hero)**: no panel, border or background; it sits on the page
   background. A muted prompt line, "Ask me anything about my research,
   projects or teaching."; three starter chips that send their text as a
   question: "What is your PhD about?", "Skills or plugins?", "What did you
   build before?"; the input (keeps its own outline, green send button); a
   small note under it: "Answers are generated by Claude." The existing chat
   modal and its full disclaimer are unchanged. Conversation messages, once a
   chat starts, follow the same floating treatment.
4. **Essays**: label "Essays" in green small caps over a rule. Each entry:
   title (Montserrat 600, 26 px, `text-wrap: balance`), one-line description
   (muted, `text-wrap: pretty`), month and year. Newest first, read from the
   `essays` collection for the current locale. No placeholders for unpublished
   essays.
5. **Footer** (shared `Footer.astro`): already carries LinkedIn, Instagram,
   GitHub, GitLab and email, so the homepage has no link row of its own.

Removed from the homepage: Services, "Architect + Programmer", the geodesic
dome, Portfolio Highlights, Recommendations, Map of Knowledge, and the
"Ready to elevate your AEC projects?" contact block.

`src/i18n/home/{types,en,pt,de}.ts` shrink to the strings that remain (meta,
role, bio, chat labels, starter questions, essays label), in all three
locales.

## 2. Essays

- New collection `essays` in `src/content.config.ts`, files in
  `src/content/essays/{en,pt,de}/<slug>.md(x)`.
- Frontmatter: the shared `pageSchema` used by every content collection:
  `Name`, `Description` (the one-line dek on the homepage), `DateStart`
  (publication date, `YYYY-MM-DD`), `Cover`, `CoverAlt`, optional `Updated`.
  Same house rules as other content: headings start at `##`, no em dashes,
  SVG covers need a `-social.png` twin.
- Route: add `"essays"` to the collection list in
  `src/pages/[...locale]/[...subpage].astro`, giving `/essays/<slug>` with the
  existing layout, "Last updated", and social image handling. Files starting
  with `_` stay unpublished, as elsewhere.
- No `/essays` index page; the homepage is the index.
- Language: Daniel writes English; pt and de translations are made at release.

Release plan, one per month:

| Month | Essay | Source thoughts |
|---|---|---|
| Nov 2026 (launch) | Code is cheap, judgement isn't | `PhD/2026-08-14_phd-from-gh-plugins-to-composable-skills`, `PhD/2026-08-14_phd-skills-as-deliverables-instead-of-grasshopper-plugin` |
| Dec 2026 | Defining "complete" is the work | `PhD/2026-10-08_defining-complete-is-itself-the-finding`, the agent-design benchmark |

| Feb 2027 | Architecture after the intern | `Research/2026-10-19_ai-in-teaching` |

The homepage ships together with the first essay; it is not published with an
empty essays list.

## 3. Work page and nav (phase 2)

- Header nav becomes **Work · CV** plus the language picker. Today the nav is
  generated from the `pages` collection (Projects, Research, Teaching); it
  changes to an explicit list.
- One list component renders projects, research and teaching entries together,
  newest first, with filter chips (All, Research, Projects, Teaching) that are
  plain links.
- Four views, each a real page with a self-referencing canonical:
  `/work` (all, new) and the existing `/projects`, `/research`, `/teaching`
  (filter preset). Same in `/pt/` and `/de/`.
- Entry URLs (`/projects/<slug>`, `/research/<slug>`, `/teaching/<slug>`,
  decks under `/teaching/<slug>/deck`) are routed by collection and do not
  change.
- Ships after phase 1.
