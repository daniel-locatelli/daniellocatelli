# Homepage Redesign, Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the services-and-portfolio homepage with a minimal, essay-led page (name, role, bio, floating AI chat with starter questions, essays list) and add an `essays` content collection, without writing the essay itself.

**Architecture:** Essays are a normal content collection using the shared `pageSchema`, routed by the existing `[...subpage].astro` at `/essays/<slug>`. A small pure module (`src/lib/essays.ts`) filters, sorts and formats essays for the homepage, so the logic is unit-testable without Astro. `HeroChat.tsx` gains starter-question chips and a floating style; the homepage is rewritten around it. Drafts are files with a leading underscore and must never be routed, listed or embedded.

**Tech Stack:** Astro 7, React 19, Tailwind CSS 4 (config in `tailwind.config.ts`, fonts `font-title` = Montserrat, `font-body`), TypeScript strict, `node:test` via `tsx --test` for unit tests, Playwright for e2e, pnpm.

**Spec:** `docs/superpowers/specs/2026-10-30-homepage-redesign-design.md`. Phase 2 (Work page, nav) is **not** in this plan.

**Visual reference:** `.superpowers/brainstorm/5836-1793371326/content/homepage-final.html` (git-ignored, on this machine). Open it in a browser to compare.

```ts
import { siteConfig } from "@/config/site";
import { getEntryLocale, getFileSlug, isPublishedId } from "./routes-helpers";

/** The fields of an essays-collection entry the homepage list needs. */
export interface EssayEntry {
  id: string;
  data: { Name: string; Description?: string; DateStart?: string };
}

/** Published essays of one locale, newest first. Undated entries are skipped. */
export function publishedEssays<T extends EssayEntry>(
  entries: T[],
  locale: string,
): T[] {
  return entries
    .filter(
      (e) =>
        getEntryLocale(e.id) === locale &&
        isPublishedId(e.id) &&
        Boolean(e.data.DateStart),
    )
    .sort((a, b) => b.data.DateStart!.localeCompare(a.data.DateStart!));
}

export function essayHref(entry: { id: string }, locale: string): string {
  const prefix = locale === siteConfig.defaultLocale ? "" : `/${locale}`;
  return `${prefix}/essays/${getFileSlug(entry.id)}`;
}

/** "2026-11-30" → "November 2026" (en), "novembro de 2026" (pt). */
export function formatEssayMonth(date: string, locale: string): string {
  return new Intl.DateTimeFormat(locale, {
    month: "long",
    year: "numeric",
    timeZone: "UTC",
  }).format(new Date(`${date}T00:00:00Z`));
}
```

```tsx
  const sendQuestion = async (question: string) => {
    const userMessage = question.trim();
    if (!userMessage || isLoading) return;

    preloadModal();
    setIsOpen(true);
    setInput("");
    setMessages((prev) => [...prev, { role: "user", content: userMessage }]);
    setIsLoading(true);
    setHasInteracted(true);

    const maxRetries = 1;
    let attempt = 0;
    let success = false;

    while (attempt <= maxRetries && !success) {
      try {
        const response = await fetch("/api/ai", {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ question: userMessage }),
        });

        if (!response.ok) {
          throw new Error(`Failed to fetch response: ${response.status}`);
        }

        const data = (await response.json()) as { answer: string };
        setMessages((prev) => [
          ...prev,
          { role: "assistant", content: data.answer },
        ]);
        fetchPreviews(data.answer);
        success = true;
      } catch (error) {
        console.error(
          `Chat error (attempt ${attempt + 1}/${maxRetries + 1}):`,
          error,
        );
        attempt++;

        if (attempt <= maxRetries) {
          await new Promise((resolve) => setTimeout(resolve, 1000));
        } else {
          setMessages((prev) => [
            ...prev,
            { role: "assistant", content: labels.errorMessage },
          ]);
        }
      }
    }

    setIsLoading(false);
  };

  const handleChatSubmit = (e: React.SyntheticEvent) => {
```
